## 1. Общая схема

Две части, работающие вместе:

| Часть | Где | Кому |
|---|---|---|
| **Бот в Telegram** | личный чат с `@uspevaika_krsk_bot` | клиенты и менеджеры |
| **Витрина (Mini App)** | страница по адресу `WEBAPP_URL` | клиенты |
| **Админка** | тот же сервер, `/admin` | только менеджеры |

Поток заказа:

```
Клиент нажимает «🛒 Меню и заказ»
        ↓
Витрина: выбирает блюда, день, интервал, оплату
        ↓
Заказ уходит боту (внутри Telegram) или на сервер (браузер)
        ↓
Сервер пересчитывает цены и остатки по menu.json, пишет в orders.db
        ↓
Менеджер получает сообщение с кнопками статусов
        ↓
Клиент получает уведомление на каждой смене статуса
```

Важно: **все цены и суммы считает сервер**, значения из витрины игнорируются. Списывание остатков идёт одной операцией под блокировкой — два одновременных заказа не продадут одно блюдо дважды.

## 2. Главное меню

Постоянная клавиатура под полем ввода. Отправляется по `/start`, остаётся на экране.

```
┌─────────────────────────────────────────┐
│  🛒 Меню и заказ                        │  ← открывает витрину (Mini App)
├──────────────────────┬──────────────────┤
│  📋 Мои заказы       │ 🚚 Доставка и оплата │
├──────────────────────┴──────────────────┤
│  📞 Связаться                           │
└─────────────────────────────────────────┘
```

У менеджера (id из `ADMIN_IDS` или добавленного в чате) появляются ещё кнопки:

```
│  👔 Менеджер        │ 📜 История        │  ← панель в чате и история заказов
│  🛠 Админка                             │  ← открывает панель управления
```

### 2.1 «🛒 Меню и заказ»

Открывает витрину внутри Telegram. Ссылка **персональная**: в ней подписанный Telegram id клиента (`…?u=<id>.<подпись>`). Поэтому заказ не теряет клиента даже на iOS, где Telegram не передаёт витрине `initData`. Подделать id нельзя — подпись не сойдётся.

Если `WEBAPP_URL` не задан, кнопки нет.

### 2.2 «📋 Мои заказы»

Последние **5** заказов этого пользователя:

```
Ваши последние заказы:

№12 · ср, 26 ноября, 12:00–14:00 · 2 176 ₽ · ✅ Принят
№9 · пн, 24 ноября, 18:00–20:00 · 3 146 ₽ · 🏁 Доставлен
```

Заказы ищутся по Telegram id. Если заказов нет:

> Заказов пока нет. Откройте «🛒 Меню и заказ» 💛

Заказы, оформленные в браузере без Telegram, здесь не появятся — они не привязаны к аккаунту.

### 2.3 «🚚 Доставка и оплата»

Справка по текущим условиям из `menu.json`:

```
Доставка по Красноярску
Минимальный заказ: 1 500 ₽
Районы и стоимость
• Железнодорожный, Советский, Центральный — бесплатно от 3 000 ₽, иначе 350 ₽
• Ленинский, Кировский, Свердловский, Октябрьский, Солнечный, Солонцы — бесплатно от 5 000 ₽, иначе 450 ₽
• За городом, не более 40 км — бесплатно от 10 000 ₽, иначе 650 ₽
Интервалы: 10:00–12:00, 12:00–14:00, 14:00–16:00, 16:00–18:00, 18:00–20:00
Дни доставки: понедельник, среда, пятница, воскресенье

Оплата: переводом при получении, наличными курьеру, картой курьеру.

Продукция шоковой заморозки: храните в морозилке при −18°, повторно не замораживайте.
```

Если районов не настроено, вместо списка районов — строка «Стоимость: N ₽, бесплатно от M ₽».

### 2.4 «📞 Связаться»

```
Телефон: +7 (923) 363-82-08
Или напишите нам в личные сообщения канала @uspevayka_krsk.
```

### 2.5 «🛠 Админка» (только менеджеры)

Открывает `/admin` внутри Telegram. Ссылка несёт подписанный токен менеджера со сроком 30 дней — иначе на iOS панель не пустила бы даже своего (там нет `initData`). Токен сразу убирается из адресной строки.

Клиент эту кнопку не видит никогда.

## 3. Витрина для клиента

Одна страница, три экрана и шторка блюда.

### 3.1 Экран «Каталог»

**Шапка** — логотип, название, слоган, город с зелёной точкой, плашки условий:

```
[Успевайка]                    ← логотип
Успевайка
Готовим мы. Живёте вы.
● Доставка по Красноярску

[от 1 500 ₽] [бесплатно от 3 000 ₽] [Самовывоз по договорённости] [Шоковая заморозка]
```

**Поиск** — по названию и описанию, регистр и «ё/е» не важны. Есть кнопка очистки ✕.

**Категории** (горизонтальная лента, липнет к верху при прокрутке):

| Категория | Иконка |
|---|---|
| Ужины и обеды | кастрюля |
| Завтраки | яйцо |
| Супы | миска |
| Наборы | подарок |
| Напитки и соусы | чашка |

На каждой — счётчик блюд.

**Карточка блюда:**

```
┌──────────────────────┐
│ [фото 4:3]           │  ← метка «Хит» / «Новинка» / «Предзаказ»
│                      │     или «Нет в наличии» поверх фото
├──────────────────────┤
│ Сырники              │
│ 500 г · 10 шт        │
│ Осталось 3 штуки     │  ← только если остаток ≤ 3
│ 420 ₽           [+]  │  ← или [−] 2 [+] когда в корзине
└──────────────────────┘
```

Нет в наличии — карточка приглушена, кнопки добавления нет.

**Корзина внизу** (липкая полоса):

```
[ Корзина 3 позиции                    1 826 ₽ ]
```

Внутри Telegram вместо неё — штатная кнопка Telegram **MainButton**: «Корзина · 1 826 ₽».

При загрузке меню показываются 6 скелетон-карточек, чтобы не было пустого экрана.

### 3.2 Шторка блюда

Открывается по фото или названию. Закрывается крестиком, кнопкой «Закрыть», щелчком по затемнению или клавишей Escape.

```
[фото 16:10]                                    [✕]
Сырники
Нежные, с ванилью…

┌──────────────┬──────────────┐
│ Вес          │ В упаковке   │
│ 500 г        │ 10 шт        │
├──────────────┼──────────────┤
│ Приготовление│ КБЖУ на 100 г│
│ Сковорода,   │ 190 / 11 /   │
│ 8 мин        │ 7 / 19       │
├──────────────┴──────────────┤
│ Хранение                    │
│ Морозилка, −18°             │
└─────────────────────────────┘

420 ₽                    [−] 2 [+]
[ Закрыть ]
```

Количество меняется прямо в шторке — она перерисовывается на месте.

### 3.3 Поведение

- **Остатки всегда актуальные.** Меню перечитывается при возврате в приложение и раз в минуту, пока оно открыто. Если блюдо разобрали, пока клиент выбирал, оно сразу помечается «Нет в наличии», а из корзины убирается с пояснением. Раньше витрина показывала старые остатки, и человек узнавал правду только при оформлении.
- **Ничего не моргает.** При добавлении в корзину обновляется только эта карточка, а не весь каталог: пересборка сетки заставляла браузер заново грузить все фото. Плюс сами фото кэшируются на 30 дней.
- **Предел количества виден.** Когда в корзине всё, что есть, кнопка «+» гаснет, а под карточкой пишется «Больше N порций нет». Попытка нажать «+» сверх остатка показывает сообщение, а не молча не срабатывает.
- **Корзина сохраняется** между открытиями (localStorage), но не дольше **20 минут без действий**. За минуту до очистки появляется предупреждение; любое действие с корзиной продлевает срок. Брошенная корзина не блокирует блюда для других — она вообще ничего не резервирует, остаток списывается только при оформлении заказа.
- **Контакты запоминаются** — имя, телефон, адрес подставляются в следующий раз.
- **Имя** подставляется из профиля Telegram, если поле пустое.
- **Светлая и тёмная тема** — следует настройке Telegram или системы.
- **Тактильный отклик** на добавление и ошибки (на поддерживаемых устройствах).

## 4. Оформление заказа

### 4.1 Экран «Ваш заказ»

**Состав заказа** — по строке на блюдо, с количеством и суммой. Можно менять прямо здесь.

```
Состав заказа
[фото] Сырники               [−][2][+]   840 ₽
       420 ₽ × 2
[фото] Куриный шашлычок      [−][1][+]   986 ₽
       986 ₽ × 1

Блюда                                  1 826 ₽
Доставка (бесплатно от 3 000 ₽)          350 ₽
Итого                                  2 176 ₽
```

**Контакты**

| Поле | Правило |
|---|---|
| Имя | обязательно |
| Телефон | обязательно, российский формат: `+7 923 363-82-08`, `89233638208`, `9233638208` |
| Адрес | обязательно, минимум 5 символов |

**Доставка**

| Поле | Что внутри |
|---|---|
| Район | выбор из районов, у каждого — порог бесплатной доставки |
| День доставки | плитки с днём недели и числом; только дни из расписания. Список дат считает сервер, поэтому часы устройства в другом часовом поясе не сдвинут день |
| Время | интервалы 10:00–12:00 … 18:00–20:00 |
| Оплата | перевод / наличные / карта |

Стоимость доставки пересчитывается на месте при смене района.

**Комментарий** — до 500 символов, например «Позвонить за 30 минут, домофон не работает».

**Кнопка** — «Оформить заказ» (внутри Telegram — MainButton «Оформить · 2 176 ₽»).

Подсказки под кнопкой:

- из Telegram: «Менеджер подтвердит заказ и напишет вам в Telegram»
- из браузера: «Мы позвоним, чтобы подтвердить заказ»

### 4.2 Проверки до отправки

Показываются над кнопкой в красной плашке:

| Ситуация | Текст |
|---|---|
| Сумма ниже минимума | «Минимальный заказ 1 500 ₽. Добавьте ещё на N ₽.» |
| Не хватает до района | «Для доставки «Район» минимальная сумма N ₽.» |
| Нет имени | «Укажите имя.» |
| Телефон короче 10 цифр | «Укажите телефон, чтобы курьер мог позвонить.» |
| Адрес короче 5 символов | «Укажите адрес доставки.» |
| Не выбран день | «Выберите день доставки.» |
| Не выбрано время | «Выберите интервал доставки.» |

### 4.3 Экран «Заказ принят»

```
        ✓
   Заказ принят

   Заказ №12
   К оплате 2 176 ₽

Менеджер подтвердит заказ, а о каждом изменении
статуса бот напишет вам в Telegram.

[ Вернуться в меню ]
```

Для заказа без Telegram: «Менеджер свяжется с вами по телефону, чтобы подтвердить заказ.»

## 5. Уведомления клиенту

Приходит в личку от бота на каждой смене статуса — и когда статус меняет менеджер в чате, и когда в админке.

| Статус | Текст клиенту |
|---|---|
| ✅ Принят | Ваш заказ №{id} принят. Готовим к отправке 💛 |
| 📦 Собран | Заказ №{id} собран и ждёт курьера. |
| 🚗 В пути | Заказ №{id} в пути. Курьер позвонит перед приездом. |
| 🏁 Доставлен | Заказ №{id} доставлен. Приятного аппетита! Будем рады отзыву 💛 |
| ❌ Отменён | Заказ №{id} отменён. Если это ошибка — напишите нам или позвоните {телефон}. |

На «Доставлен» к сообщению прикладывается главное меню с кнопками.

Клиенту без Telegram (заказ с сайта) ничего не отправляется — с ним связываются по телефону.

## 6. Админка (панель управления)

Открывается кнопкой «🛠 Админка» или командой `/admin`. Четыре раздела внизу экрана.

### Вход

| Способ | Как |
|---|---|
| Из Telegram | кнопка «🛠 Админка» — доступ по подписанному токену |
| В браузере | пароль `ADMIN_PASSWORD` |

Сессия — 12 часов. После 8 неудачных попыток пароля вход с адреса блокируется на 5 минут.

### 6.1 Раздел «Меню»

Список позиций: фото, название, цена, остаток, метка. У каждой:

| Кнопка | Что делает |
|---|---|
| ⏸ / ▶ | поставить в стоп (остаток 0) / вернуть в продажу с указанным количеством |
| ✏ | редактировать |
| 🗑 | удалить (с подтверждением) |

**Форма блюда** (кнопка «Новое блюдо» или ✏):

| Поле | Обязательно | Пример |
|---|---|---|
| Название | да | Сырники |
| Цена, ₽ | да, больше нуля | 420 |
| Остаток, шт | — | 15 |
| Категория | да | Завтраки |
| Вес | — | 500 г |
| В упаковке | — | 10 шт |
| Метка | — | Хит / Новинка / Предзаказ / Ограничено / без метки |
| КБЖУ | — | 190 / 11 / 7 / 19 |
| Приготовление | — | Духовка 180°, 25 мин |
| Описание | — | Нежные, с ванилью… |
| id | — | сгенерируется из названия |

**Фото** — загрузка файлом до 8 МБ. Сервер сам обрезает под 4:3 и делает два размера: 720×540 и 1080×810 (retina), формат WebP.

**Категории** — добавить, переименовать, сменить иконку, удалить. Категорию с блюдами удалить нельзя: «В категории есть блюда — сначала перенесите их».

### 6.2 Раздел «Заказы»

Фильтры по статусу с счётчиками: Все · Новый · Принят · Собран · В пути · Доставлен · Отменён.

**Карточка заказа** (свёрнутая — номер, статус, время, имя, сумма; разворачивается нажатием):

```
№12  [✅ Принят]  25.11 14:03 · Анна        2 176 ₽

Клиент      Анна, +7 923 000-00-00
Откуда      @anna  ← ссылка на профиль
            или «Telegram id 123456789»
            или «с сайта, без Telegram»
Адрес       ул. Ленина 1, кв. 5 · Железнодорожный
Доставка    вт, 26 ноября, 12:00–14:00
Оплата      Наличными курьеру
Комментарий домофон не работает

Сырники × 2                        840 ₽
Куриный шашлычок × 1               986 ₽
Доставка                           350 ₽

[Новый][Принят][Собран][В пути][Доставлен]  [Отменить]
```

**Заказ по телефону.** Кнопка «Заказ по телефону» над списком: менеджер выбирает блюда со склада, вписывает контакты и адрес — заказ сразу списывает остатки и попадает в статистику, как обычный. Источник помечается «phone». Это убирает ручное сведение остатков: если менеджер продал последнее по телефону, витрина сразу показывает «Нет в наличии».

**Изменить состав** — кнопка в карточке открытого заказа. Убрали блюдо — остатки вернулись; добавили — списались. Сумма и доставка пересчитываются, сообщение в чате менеджеров обновляется. Закрытые заказы (доставлен, отменён) править нельзя — их отменяют.

**Смена статуса** — кнопкой. Клиент сразу получает уведомление.
**Отмена** — с подтверждением «Отменить заказ №12? Остатки вернутся в меню.» Остатки действительно возвращаются.

Закрытые заказы (доставлен, отменён) повторно не открываются: «Заказ уже закрыт».

### 6.3 Раздел «Статистика»

Выбор периода: 7 / 14 / 30 / 90 дней.

**Сводка** — четыре плитки:

- Сегодня: выручка и число заказов
- Всего заказов (без отменённых)
- Выручка за всё время
- Средний чек

**Выручка по дням** — полосы по датам.

**Что берут чаще** — топ-8 блюд по сумме: количество и выручка.

**Статусы заказов** — сколько заказов в каждом статусе.

Все изменения видны клиентам сразу — перезапуск не нужен.

## 7. Команды бота

### Для всех

| Команда | Действие |
|---|---|
| `/start` | приветствие и главное меню |
| `/id` | показать chat id и свой user id |

### Только для менеджеров (`ADMIN_IDS`)

У остальных команды молча игнорируются.

| Команда | Действие | Пример |
|---|---|---|
| `/admin` | открыть панель управления | `/admin` |
| `/menu` | меню менеджера с кнопками | `/menu` |
| `/orders` | активные заказы (до 15) | `/orders` |
| `/history [стр]` | история всех заказов, по 6 на страницу | `/history 2` |
| `/stock` | все блюда с остатками, светофор 🔴🟡🟢 | `/stock` |
| `/admins` | список менеджеров с кнопками | `/admins` |
| `/addadmin` | добавить менеджера (ответом на сообщение или по id) | `/addadmin` / `/addadmin 123456789` |
| `/deladmin <id>` | убрать менеджера, добавленного в чате | `/deladmin 123456789` |
| `/stop <блюдо>` | убрать в стоп-лист | `/stop тефтели` |
| `/set <блюдо> <кол-во>` | задать остаток | `/set сырники 15` |

### Меню менеджера с кнопками

Команда `/menu` или кнопка **«👔 Менеджер»** в главном меню открывает панель:

```
[📋 Активные заказы] [📜 История]
[📦 Остатки]         [👥 Менеджеры]
```

- **Активные заказы** — те, что ещё не доставлены и не отменены.
- **История** — все заказы по 6 на страницу, кнопки «← Новее» и «Старее →».
- **Остатки** — светофор по всем блюдам.
- **Менеджеры** — список с источником доступа («из .env» или «добавлен в чате»).

У каждого раздела есть кнопка «← В меню». Сообщение редактируется на месте, а не плодит новые.

### Как добавить менеджера

Два способа, оба в чате:

1. **Ответом на сообщение** — надёжный: ответьте на любое сообщение человека в группе командой `/addadmin`. Telegram сам сообщит его id.
2. **По id** — `/addadmin 123456789`.

По `@нику` добавить нельзя: Bot API не отдаёт id по нику. Бот так и объясняет.

Новый менеджер должен открыть бота и нажать `/start`, чтобы появились кнопки.

**Убрать** — `/deladmin <id>`. Менеджеров из `ADMIN_IDS` (`.env`) убрать через бота нельзя — только правкой файла и перезапуском: иначе можно случайно остаться без доступа. Убрать самого себя тоже нельзя.

Пример `/stock`:

```
Остатки
🟢 Сырники — 15 шт · syrniki
🟡 Куриный шашлычок в беконе — 3 шт · shashlik-bacon
🔴 Венские вафли — 0 шт · vienna-waffles
🔴 Тефтели в томатном соусе — 0 шт · meatballs-tomato
…

/stop <блюдо> — убрать в стоп
/set <блюдо> <кол-во> — задать остаток
```

Поиск по названию нестрогий: `/set с 7` найдёт «Сырники». Если подходят несколько блюд, бот покажет их id.

### Кнопки статусов в сообщении о заказе

Менеджеру в чат (`ADMIN_CHAT_ID`) приходит сообщение о новом заказе с кнопками. Показываются **два следующих** статуса по цепочке:

```
Новый → Принят → Собран → В пути → Доставлен
```

Плюс «✏️ Изменить состав» и «❌ Отменить». После «Доставлен» и «Отменён» кнопки исчезают.

### Правка заказа в чате — только убрать

Кнопка «✏️ Изменить состав» открывает список блюд этого заказа:

```
Заказ №12: убрать лишнее
Уменьшайте количество — убранное вернётся на склад.

• Сырники — 4 шт
• Домашний морс — 2 шт
• Куриные котлеты классические — 2 шт

Добавить блюдо — в веб-панели (кнопка ниже).

[− Сырники]              [✖️ убрать]
[− Домашний морс]        [✖️ убрать]
[− Куриные котлеты]      [✖️ убрать]
[✅ Сохранить] [↩️ Вернуть как было]

➕ Добавить блюдо — открыть панель   ← ссылка в тексте
```

- «−» — минус одна порция, «✖️ убрать» — убрать блюдо целиком.
- **Добавить** в чате нельзя: там нет ни фото, ни поиска. Ссылка «➕ Добавить блюдо» открывает веб-панель сразу на нужном заказе. Ссылкой, а не кнопкой: Telegram не принимает `web_app`-кнопки внутри обычного сообщения и отвечает `BUTTON_TYPE_INVALID` — менеджер не увидел бы вообще ничего.
- **Сохранить** возвращает убранное на склад, пересчитывает сумму и обновляет карточку.
- **↩️ Вернуть как было** выбрасывает изменения.
- Нельзя убрать все блюда — тогда «❌ Отменить».
- Закрытые заказы не редактируются.

### Добавление блюд — в веб-панели

В панели в карточке заказа кнопка «Изменить состав» открывает форму: **поиск по блюдам** и «+»/«−» по каждой позиции. Поиск ищет по названию и описанию, прощает регистр и «ё/е», находит по основе слова («говядина» → «с говядиной»).

Порядок на экране: поле поиска → **результаты поиска** (с подписью «Найдено: N») → «Уже в заказе». Результаты специально выше: при длинном заказе иначе кажется, что поиск ничего не нашёл. Если по запросу ничего нет, так и пишется.

Добавили — списалось со склада, убрали — вернулось. Заодно там правятся имя, телефон, адрес, день и время.

Ссылка из чата ведёт на `/admin?order=12&ut=<токен>`: панель открывает нужный заказ и сразу опознаёт менеджера по подписанному токену — пароль не нужен. Токен тот же, что у кнопки «🛠 Админка», действует 30 дней; когда истечёт, пришлите `/admin` ещё раз.

Не-менеджеру: «Менять статус могут только менеджеры».

### Шрифт

**Manrope** (Google Fonts), веса 400–800. Запасной набор — системные шрифты. Заголовки с плотным начертанием и отрицательным межбуквенным интервалом.

### Форма и объём

- Скругления: 18 px у карточек, 12 px у полей, 999 px у «таблеток».
- Тень мягкая, двухслойная, с зеленоватым оттенком (не серой).
- Карточки приподнимаются на 2 px при наведении (на устройствах с мышью), фото плавно увеличивается.

### Иконки

Рисованные SVG-контуры (кастрюля, яйцо, миска, подарок, чашка, лист) — эмодзи на части устройств выглядят по-разному или не отображаются. Эмодзи остались только в кнопках меню бота и статусах.

### Движение

- Появление шторки: снизу вверх за 240 мс с плавным замедлением.
- Появление корзины и тостов: мягкое, до 220 мс.
- **Анимации отключаются** при системной настройке «уменьшить движение».

### Доступность

- Все интерактивные элементы доступны с клавиатуры, видимая рамка фокуса.
- Семантические роли: `role="radiogroup"` у выбора дня и времени, `aria-live` у каталога и тостов.
- Поиск с `aria-label`, кнопки закрытия с подписями.
- Шторка закрывается по Escape.

### Служебное

- Логотип — `img/logo@2x.webp`, иконка — `favicon.png`.
- Фото блюд 4:3 в WebP, с вариантом `@2x` для экранов высокой плотности.
- Адаптив: карточки встают в сетку автоматически — одна-две колонки на телефоне, три на широком экране. Ширина ограничена 600 px, чтобы на мониторе всё не растягивалось.

## 10. Правила и ограничения

### Заказ

| Ограничение | Значение |
|---|---|
| Позиций в заказе | до 50 (дубли склеиваются) |
| Количество одной позиции | до 999 |
| Минимальный заказ | из настроек, сейчас 1 500 ₽ |
| Пауза между заказами одного клиента | 5 секунд |
| Заказов с одного IP (сайт) | 8 в час |
| День доставки | только из расписания |
| Время | только из списка интервалов |
| Оплата | только из списка способов |

### Остатки

- Списание — атомарно, под общей блокировкой, **в момент оформления заказа**. Ждать, пока менеджер нажмёт «Принят», не нужно: иначе двое успели бы купить одно и то же блюдо. Заказ лежит в статусе «Новый», а остаток уже уменьшен.
- Если блюда не хватает, в заказ попадает столько, сколько есть, а клиент видит пометку:
  «⚠️ Куриный шашлычок в беконе — осталось только 12 шт, положили их».
- Если всё закончилось — заказ не принимается, остатки не списываются. В отказе называются блюда:
  ««Куриный шашлычок в беконе» уже закончилось — его успели заказать. Выберите другое блюдо в меню 💛».
- При отмене заказа остатки возвращаются.
- Если остатков не хватило до минимальной суммы или до минимума района — заказ отклоняется, остатки не списываются.

### Актуальное меню

24 блюда в 5 категориях, например: Куриный шашлычок в беконе (986 ₽, Новинка), Пастуший пирог (650 ₽, Хит), Тефтели в томатном соусе (540 ₽), Сырники (420 ₽), борщ, солянка, том-ям, наборы, морс, соус.

Цены точные там, где в `menu.json` указано `price_source: "channel"`; остальные — примерные, их надо заменить на реальные.

## 11. Что происходит при ошибках

| Ситуация | Что видит клиент |
|---|---|
| Меню недоступно (битый `menu.json`) | «Меню временно недоступно, попробуйте через минуту.» |
| Корзина пуста | «Корзина пуста. Выберите блюда в меню 💛» |
| Всё закончилось | «Все блюда из корзины закончились 😔 Загляните в меню — там есть другие.» |
| Блюдо убрали из меню | «Меню обновилось, и этих блюд в нём больше нет. Откройте меню и соберите заказ заново.» |
| Ниже минимальной суммы | «Сумма заказа N ₽ меньше минимальной (M ₽). Добавьте блюд в меню и оформите снова.» |
| Не хватает до района | «Для доставки в район «…» минимальная сумма N ₽…» |
| Слишком часто | «Заказ уже принят. Если нужно оформить ещё один — подождите пару секунд.» |
| Много заказов с адреса | «Слишком много заказов с этого адреса. Позвоните нам, оформим вручную.» |
| Сбой базы | «Не удалось сохранить заказ. Попробуйте ещё раз или позвоните нам.» |
| Telegram недоступен | заказ **всё равно сохраняется** и виден в админке |
| Неверный токен бота | бот пишет понятную ошибку в лог, витрина продолжает работать |
| Нет связи с Telegram | подсказка про `TELEGRAM_PROXY` |

Менеджеру при недоступности чата: заказ уходит в личку первому из `ADMIN_IDS`. Если недоступен и он — запись остаётся в базе и в админке.
