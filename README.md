# Успевайка

Telegram-бот с витриной (Mini App) для магазина домашних полуфабрикатов:
каталог с фото и остатками, корзина, оформление доставки, уведомления клиенту
о каждом статусе заказа, панель управления и статистика.

Домашние полуфабрикаты шоковой заморозки, Красноярск.

## Установка на сервер

```bash
# 1. скачать последний релиз
curl -fsSL -o uspevaika.tar.gz \
  https://github.com/iamlex92/Uspevaika/releases/latest/download/uspevaika-release.tar.gz

# 2. распаковать и запустить установщик
mkdir -p ~/uspevaika && tar -xzf uspevaika.tar.gz -C ~/uspevaika
cd ~/uspevaika && sudo ./install.sh
```

Установщик спросит токен бота, домен, ваш Telegram id и (по желанию) чат для
заказов. Дальше сам поставит зависимости, настроит HTTPS и поднимет службу.

Подробно — [DOCS.md](DOCS.md). Полное удаление — `sudo ./uninstall.sh`.

## Что умеет

**Клиент** (в Telegram): витрина с фото, поиск, корзина с сохранением, выбор
района и дня доставки, оплата, комментарий. Уведомления о статусе заказа.

**Менеджер**: заказы с кнопками статусов прямо в чате, правка состава,
меню и остатки, фото блюд, условия доставки, статистика, менеджеры.

Всё описание — [app/ОПИСАНИЕ-БОТА.md](app/ОПИСАНИЕ-БОТА.md).

## Состав

```
app/                    приложение
  bot.py                бот + веб-сервер витрины
  admin.py              панель управления и её API
  webapp/               витрина, админка, фото
  menu.json             меню и остатки (данные!)
  tests/                проверки
install.sh              установка
uninstall.sh            полное удаление
autoupdate.sh           автообновление из релизов
deploy/                 настройка nginx, Caddy, диагностика
```

## Требования

- Debian 12 / Ubuntu 22.04+ (Python 3.10+)
- 1 CPU, 1 ГБ RAM, 10 ГБ диска
- Домен, направленный на сервер (Telegram открывает Mini App только по https)

## Автообновление

Сервер может сам проверять релизы здесь и обновляться ночью:

```bash
sudo nano /etc/uspevaika-update.conf    # GITHUB_REPO="iamlex92/Uspevaika"
sudo systemctl enable --now uspevaika-update.timer
```

Каждое обновление сверяет контрольную сумму, сохраняет данные и откатывается
при неудаче. Подробно — раздел «Автообновление» в [DOCS.md](DOCS.md).

## Проверки

```bash
cd app && python3 -m unittest discover -s tests -v
```

185 проверок: логика заказа и остатков, админ-панель и CSRF, приём заказа с
сайта и `initData`, валидация, интеграционный прогон настоящего aiogram-бота
против локального поддельного Bot API. Сеть не нужна.
