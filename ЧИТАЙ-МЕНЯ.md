# Релиз «Успевайка» — 2026-11-25

Telegram-бот с витриной (Mini App), приёмом заказов, панелью управления и статистикой.

## Установка — две команды

```bash
# 1. на сервер
scp uspevaika-release-2026-11-25.tar.gz user@server:/tmp/
ssh user@server
mkdir -p ~/uspevaika && tar -xzf /tmp/uspevaika-release-2026-11-25.tar.gz -C ~/uspevaika
cd ~/uspevaika

# 2. установить — дальше он всё спросит сам
sudo ./install.sh
```

Установщик спросит:

```
1. Токен бота от @BotFather       8123456789:AAH...
2. Домен для витрины              uspevaika.ru
3. Ваш Telegram id                (узнать: /id в боте)
4. Chat id группы                 необязательно, Enter — пропустить
```

И сам: поставит зависимости, настроит HTTPS через Caddy (с сертификатом),
поднимет службу с автоперезапуском, проверит связь с Telegram.

Когда закончит — откройте бота, отправьте `/start`, нажмите «🛒 Меню и заказ».

## Удаление — одна команда

```bash
sudo ./uninstall.sh          # спросит, что удалять
sudo ./uninstall.sh --all    # удалить всё без вопросов
```

Перед удалением данных создаётся архив `/root/uspevaika-data-<дата>.tar.gz`.
Убирает службу, файлы, пользователя, конфиг прокси и сертификат.

## Состав архива

| Файл | Что это |
|---|---|
| `install.sh` | установщик: вопросы, зависимости, HTTPS, проверка |
| `uninstall.sh` | полное удаление с выбором глубины и бэкапом данных |
| `deploy/setup-nginx.sh` | настройка nginx (подключает сайт, убирает заглушку) |
| `deploy/setup-caddy.sh` | настройка Caddy (сертификат автоматически) |
| `deploy/doctor.sh` | диагностика: где именно обрыв |
| `uspevaika.service` | служба systemd |
| `DOCS.md` | подробная инструкция: HTTPS, бэкап, обновление, перенос, проблемы |
| `app/` | приложение: код, витрина, админка, фото, меню, тесты |
| `app/ОПИСАНИЕ-БОТА.md` | полное описание бота: кнопки, экраны, дизайн |

## Обновление

```bash
mkdir -p ~/uspevaika-new && tar -xzf новый-релиз.tar.gz -C ~/uspevaika-new
cd ~/uspevaika-new && sudo ./install.sh
```

На вопросы жмите **Enter** — прежние значения подставлены. Служба перезапустится сама.

Сохраняются: `.env`, заказы (`orders.db`), **остатки и цены** (`menu.json`),
фото, загруженные через админку. Обновляются только код и страницы.

Перед копированием создаются резервы `menu.json.bak.<дата>` и `orders.db.bak.<дата>`.

Сбросить всё к исходному из релиза: `sudo ./install.sh --fresh` (удалит заказы и настройки).

## Что проверено перед сборкой

- **182 теста** проходят в чистом окружении (без `.env`, как на новом сервере)
- **диалог установщика**: верный ввод, неверный токен, домен с `https://`, id с буквами, пропуск группы, несколько менеджеров — 11 проверок
- **логика удаления**: бэкап создаётся реально, служба останавливается, файлы
  и пользователь удаляются, в режиме «сохранить» данные остаются
- **47 проверок структуры архива** и ключевых деталей скриптов

## Перед запуском в бой

1. **Остатки** — у трёх блюд в `app/menu.json` остаток 0. Поставьте реальные в админке.
2. **Цены** — точны там, где указано `price_source: "channel"`, остальные примерные.
3. **Телефон и условия доставки** — проверьте «Настройки» в админке.
